# v2.2.1 补丁说明

`acs-gongkao-geo-research v2.2.1` 是发布版 v2.2 之上的兼容性与客户报告体验补丁。底层 Run 数据 schema 仍为 `2.2`，不改变 GEO 测量方法、指标定义、资产评分权重或冻结原始采样证据。

## 不变项

- Market Universe / Measurement Target 方法不变；
- AI Answer Measurement 定义不变；
- Nomination / Top3 / First Mention / Citation 等底层指标定义不变；
- GEO Asset Readiness 七维权重不变；
- Concept Ownership 强度带宽不变；
- 原始 AI Sampling Evidence 冻结规则不变；
- 唯一正式输出仍为 `deliverables/report.docx`。

## 首次运行修复

- Stage 1 尚未产生 `ai_emergent_entities.csv` 时，Target Audit 不再要求人为创建未来阶段的空文件；
- Stage 1 先审核已知研究主体，正式 AI 测量后再对新出现且已解析的主体做第二轮 target closure；
- 新建研究主体池增加 `discovery_evidence_urls`，准备进入正式研究的主体至少保留一条可核验公开来源；
- 旧 v2.2 冻结 Run 没有该新列时继续兼容，不追溯性判失败。

## 中文客户报告

正式 Word 报告从“工程审计输出”重构为“客户可读咨询报告”：

- 简体中文优先；
- 不展示内部字段、内部枚举、CSV/JSON/Python 文件名或原始对象；
- `Top3` 改为“前三出现率”，`First Mention` 改为“第一位出现率”；
- “机构题 / IP题”不再进入客户报告，改为“机构推荐类问题 / 老师推荐类问题”；
- `IP` 在普通客户正文中优先写为“个人品牌”；
- 无引用链时引用率为“不适用”，不得写成 0%；
- 证据不足的主体写“暂不评分”，不得画成 0 分；
- 诊断文字中的资产分与等级必须与最终资产评分数据一致；
- 工程审计底稿仍完整保留在 Run 目录，但不进入客户 DOCX。

## 图表第二轮调整

首次 v2.2.1 视觉验收发现原“AI 可见度 × GEO 资产基础”散点图仍存在标签重叠、匿名点，以及机构推荐类与老师推荐类两套分母混在同一图中的问题。

因此：

- 总览图不再使用散点；
- 改成“重点优化机会”对比图；
- 机构推荐类与老师推荐类分别使用各自提名率中位数筛选，不跨题型混用分母；
- 只展示有名称的机会主体，不允许匿名点；
- 同时展示资产基础得分与 AI 提名率，但两项分别解读，不相加为未经验证的综合分；
- 资产图标题明确为“前 15 名”，不再暗示覆盖所有可评分主体；
- 概念占位继续使用直接可读的 Top 10 横向条形图。

## 客户语言与 QA 门禁

自动报告门禁新增/加强：

- 阻断 `Top3`、`机构题`、`IP题`；
- 阻断 `Metrics`、`Entity Resolution`、`Query Matrix`、`citations`、`page mention` 等开发者语言；
- 阻断内部字段、snake_case、工程文件名与 Python/JSON 原始对象；
- 原 Answer 无引用链时，同时要求出现“不适用”并禁止“引用率为 0/0%”的矛盾表述；
- 增加客户术语泄漏和引用率 0% 的负向回归测试。

## 旧报告兼容

v2.2 已经生成的旧 `report.docx` 不满足 v2.2.1 客户报告产品契约。升级后应使用原有持久化研究数据**重新生成报告层**；不需要、也不得为了报告升级去改写冻结的 AI Answers、原始 Mention、Annotation、Resolution 或其他 Measurement Evidence。

## 发布前验证

1. `python3 -m py_compile scripts/*.py` PASS；
2. `python3 scripts/test_v22.py` full dependencies 0 SKIP；
3. 首次运行 Stage 1 Target Audit 无 emergent 文件仍能正确通过；
4. 新正式主体缺发现证据 URL 时 confirmation 必须被阻断；
5. 现有合规 v2.2 RC 不回退；
6. Fresh Run 广东报告重新生成后 report strict / DOCX QA PASS；
7. 人工检查客户报告全中文、无“机构题/IP题”等内部简写、图表直观且无匿名点；
8. 不重新采样原始 AI Answer，除非验证首次运行本身明确需要新的 Fresh Run。
