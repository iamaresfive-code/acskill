# v2.2.1 补丁说明

`acs-gongkao-geo-research v2.2.1` 是基于 v2.2 的小版本修复。

## 不变项

以下内容不变：

- Run 数据 `schema_version` 仍为 `2.2`；
- Market Universe / Measurement Target 方法不变；
- AI Answer Measurement 定义不变；
- Nomination / Top3 / First Mention / Citation 等底层指标定义不变；
- GEO Asset Readiness 七维权重不变；
- Concept Ownership 强度带宽不变；
- 原始 AI Sampling Evidence 冻结规则不变；
- 唯一正式输出仍为 `deliverables/report.docx`。

## 修复项

### 1. Stage 1 Target Audit 次序

Stage 1 尚未产生 `ai_emergent_entities.csv` 时，`apply_measurement_target_audit.py` 将 emergent 集合视为空，不再要求人为创建未来阶段的空文件。

正式 AI 测量后如解析出新的 emergent 主体，再做第二轮 Target Audit 收口。

### 2. 新研究主体的发现证据

v2.2.1 新建的 `market_universe.csv` 增加可选迁移字段：

```text
discovery_evidence_urls
```

新建 Universe 中，准备进入正式研究的主主体在确认前至少要有 1 条可核验公开 URL。旧 v2.2 冻结 Run 如果没有该列，不追溯性判失败。

### 3. Citation N/A

若原始 AI 回答没有提供 citations，底层数据仍保持事实状态；客户 DOCX 中引用率显示为“不适用”，不得展示为 0% 或解释为零引用。

### 4. 中文客户报告

正式 DOCX 调整为简体中文客户报告：

- 结论与行动优先；
- 技术字段后置或隐藏；
- 内部 enum、CSV/JSON/Python 文件名、Run 清单不进入客户正文；
- Python/JSON 原始对象字符串直接阻断；
- 图表改为中文、直接标数值、减少稀疏和开发者式可视化；
- 增加“AI 可见度 × GEO 资产基础”机会矩阵；
- 概念热力图改为概念占位 Top N；
- 证据不足主体显示“暂不评分”，不落成 0。

## 验证要求

发布 v2.2.1 前必须：

1. `python3 -m py_compile scripts/*.py` PASS；
2. `python3 scripts/test_v22.py` full dependencies 0 SKIP；
3. 首次运行 Stage 1 Target Audit 无 emergent 文件仍能正确通过；
4. 新正式主体缺发现证据 URL 时 confirmation 必须被阻断；
5. 现有合规 v2.2 RC 不回退；
6. Fresh Run 广东报告重新生成后 report strict / DOCX QA PASS；
7. 人工视觉检查客户报告全中文、图表直观、无工程信息泄漏；
8. 不重新采样原始 AI Answer，除非验证首次运行本身明确需要新的 Fresh Run。
